# ROW-1 frozen source fixtures

These PlainXML files are the source-evidence channel for the ROW-1 pedestrian
right-of-way experiment. The `priority` attribute is intentionally explicit in
the two known unsignalized fixtures and intentionally absent in the unknown
fixture. The signalized fixture changes only the center node control type.

Generated `.net.xml`, request/foes rows and SUMO runtime behavior are model
claims or runtime observations. They are never used to construct the expected
right-of-way answer.
